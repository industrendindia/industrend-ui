# Indus Trend UI

Responsive storefront experience for [industrend.in](https://industrend.in), built with React, Vite and TypeScript.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm ci
npm run build
```

The production output is written to `dist/`. VPS and Nginx instructions are available in [`deploy/DEPLOY.md`](deploy/DEPLOY.md).

## Current scope

- Responsive editorial storefront
- Store and artisan discovery
- Curated product presentation
- Brand story and contact capture
- Login entry point ready for future backend integration
